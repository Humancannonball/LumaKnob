# Design material

- `device-test-ui.png` is the current raised/recessed shared-step device-test
  UI with the live signal-backplane visual system, rendered on the Linux
  simulator path; Windows replaces the simulated selector with discovered WMI,
  DDC/CI, and shade-only targets and supplies the guarded gamma/warmth ramp
  backend.

Historical concept and M0 captures are kept outside the public repository so
the checked-in visual represents the current product rather than abandoned UI.

Production controls should remain original and code-drawn. Candidate fonts and
icons must pass the notice process in `PROJECT.md` before being bundled.
