# Security

Security fixes target `main` and the newest alpha.

Report vulnerabilities through
[GitHub private reporting](https://github.com/Humancannonball/LumaKnob/security/advisories/new),
especially anything that can strand a user behind a shade or compromise a
release. Do not put sensitive reports in public issues.

Remove usernames, EDID serial numbers, and unrelated machine data from logs.
LumaKnob will never ask users to disable SmartScreen, antivirus, or UAC.
