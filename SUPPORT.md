# Support

Use [issues](https://github.com/Humancannonball/LumaKnob/issues) for bugs and
the [device form](https://github.com/Humancannonball/LumaKnob/issues/new?template=device-report.yml)
for monitor results. Include the app version, Windows version, monitor model,
connection, and short reproduction steps. Remove private data from logs.

Recovery: press **Ctrl+Alt+Home**, use tray **Exit**, or press
**Ctrl+Alt+Delete** and sign out.

Report security problems privately through [SECURITY.md](SECURITY.md).
