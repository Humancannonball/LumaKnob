# Support

LumaKnob is a volunteer-run alpha, so support is best-effort.

- Search [existing issues](https://github.com/Humancannonball/LumaKnob/issues)
  before opening a new report.
- Use the bug form for repeatable software problems and the device form for
  monitor, GPU, dock, cable, DDC/CI, shade, HDR, or gamma behavior.
- Include the LumaKnob version, Windows version, monitor model, connection type,
  expected result, actual result, and minimal reproduction steps.
- Use **COPY LOG** for the current local session, then remove unrelated system
  inventory before posting. Never include EDID serial numbers or usernames.

If a shade is too dark, press **Ctrl+Alt+Home**, use tray **Exit LumaKnob**, or
press **Ctrl+Alt+Delete** and sign out from the undimmed secure desktop.

Security-sensitive reports belong in the private channel described in
[SECURITY.md](SECURITY.md), not in a public issue.
